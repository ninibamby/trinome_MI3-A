# FlipTech trinome_MI3-A

Projet réalisé en langage C dans le cadre d’un projet de programmation.

Le jeu est une adaptation du jeu **Flip 7**.

---

# Compilation du projet

Le projet se compile avec `gcc` sous Linux grâce au Makefile fourni.

Dans le terminal, placez-vous dans le dossier du projet puis tapez :

```bash
make

ensuite

FlipTech

./FlipTech
```
